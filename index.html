Getting started

From download to your first record.

KoshFlow keeps its working database in your local user profile. You can run the source directly or use the portable executable from a published release.

Download or run

Use the portable executable from a verified GitHub Release, or follow the source setup instructions below.

Set up your workspace

Create the local owner account and enter your business identity and relevant tax details.

Configure products and documents

Add customers, suppliers and catalog products; set invoice branding and payment details in Settings.

Back up and verify

Create a backup, test the restore path with a copy, and verify totals and reports against source records.

Help & guides

Clear steps for everyday work.

These guides cover the current release's main workflows. Menu names can change between versions; use the release notes and repository README for version-specific updates.

Browse the source documentationReport a problem
Install the Windows executable
  1. Open the latest release on GitHub and download KoshFlow.exe if the release includes it.
  2. Save it in a folder you control and run it. KoshFlow stores its database separately in your local application-data directory.
  3. The current build is unsigned. Download only from the official repository and verify a release before running it.

If no executable appears under release assets, the release build workflow has not yet published a binary. Use the source installation instructions in the repository README.

Install and run the source

Requirements: Python 3.11 or newer. From PowerShell in the repository root:

python -m venv .venv .\\.venv\\Scripts\\Activate.ps1 python -m pip install -r requirements.txt python main.py

First launch opens workspace setup if the database has no owner account. Later launches use the login screen.

Create and manage a bill
  1. Open Billing and select Create bill.
  2. Select or enter a customer and add products/services, quantities, discounts and applicable tax.
  3. Review the totals and payment terms before issuing the document.
  4. Generate the PDF from the saved bill and confirm the business header, customer details, amounts and payment instructions before sharing.

Issued financial documents should use the relevant documented correction or cancellation flow rather than being silently overwritten.

Use Quick Billing at the counter
  1. Search a pre-added item by name, SKU or barcode.
  2. Enter the quantity separately and add the selected item.
  3. Type a customer name and select an existing match if one appears; otherwise enter details for a new walk-in customer.
  4. Review available stock, current sale and payment method before checkout.

Quick Billing validates stock during checkout. HSN/SAC suggestions are not authoritative; verify classification and tax rate before statutory use.

Export financial and operational reports
  1. Open Reports and choose the requested statement or register.
  2. Set the period or as-of date and run the report.
  3. Review the report's source period and reconcile key numbers against invoices, purchases, payments and journals.
  4. Choose PDF for a formatted report or CSV for further analysis.

Report generation does not submit statutory returns to a government portal.

Configure notifications and test delivery
  1. Open Settings, then Notifications.
  2. Choose native desktop notifications and in-app categories.
  3. Use Test notification and read the result message.
  4. If Windows does not show a native alert, check notification permissions and Focus/Do Not Disturb settings.

Delivery depends on operating-system support. The app provides an in-app fallback where available.

Create and restore a backup
  1. Open Settings, then Data & Backups.
  2. Create a backup and wait for the verification result.
  3. Keep another copy somewhere separate from the computer containing the working database.
  4. Test a restore against a copy before replacing the primary database.

Backups in this version are standard SQLite files and are not encrypted by the application. Store them in a protected location.

Developer documentation

Understand the system before extending it.

KoshFlow separates the Qt presentation layer from database access and business services. Financial rules belong in services and should be covered by tests.

Stack and architecture

  • Python 3.11+ and PySide6 / Qt Widgets.
  • SQLite with local schema initialization and migrations.
  • Argon2 password hashing.
  • ReportLab and Pillow for branded PDF generation.
  • Service modules for bills, inventory, customers, accounting, reports, notifications and dashboard aggregates.
  • pytest for logic, migrations and workflow contracts.

Run checks locally

python -m pip install -r requirements.txt python -m pip install pytest python -m compileall -q koshflow main.py python -m pytest -q

Run the suite from the exact branch you intend to publish. Keep fixtures synthetic and never commit a business database or invoice containing real customer records.

Accounting change checklist

  • Use Decimal for monetary calculations.
  • Make posting idempotent for each source document.
  • Test debit/credit equality and reversals.
  • Check stock and account-balance side effects together.
  • Include date range or as-of context in reports.
  • Keep audit history for posted documents and adjustments.

Frequently asked questions

Before you install.

Important details about data storage, executable downloads, tax reporting and the current development status.

Does KoshFlow upload business data to a cloud database?

The current application is local-first and stores its working records in a local SQLite database. External actions such as opening WhatsApp or checking the website's release feed require network access. AI Business Insights is not presented as active in v0.6.3.

Where is the Windows executable?

Open the repository's Releases page and download KoshFlow.exe if the release includes it. The included GitHub Actions workflow builds the portable executable when a version tag is pushed. A source ZIP alone is not the executable.

Is KoshFlow a statutory GST filing tool?

No. It provides accounting and GST-supporting reports, but those reports do not file returns, submit e-invoices or create an e-way bill with a government portal. Verify classifications, tax rates and report figures before statutory use.

Are local backups encrypted?

Backups are standard SQLite files in this release and are not encrypted at rest by the app. Keep backup copies protected by your operating-system account and appropriate disk encryption.

Can I use KoshFlow on macOS or Linux?

Windows is the intended and documented desktop target. Although Python and Qt can run on other platforms, those platforms are not officially validated by this release.

Can I redistribute or modify the source?

The current source snapshot contains no LICENSE file. Until the repository owner adds a license, do not assume permission to reuse, modify or redistribute the code.
